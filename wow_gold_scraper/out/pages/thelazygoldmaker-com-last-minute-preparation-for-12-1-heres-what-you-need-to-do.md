# Last minute preparation for 12.1, here's what you need to do! - The Lazy Goldmaker

12.1 is on final approach, so let’s take a loot at what last minute prep you can do!
# Farm abundance
If you are as lazy as I am and missing epic profession gear, make sure you do abundance events. Now that you can use 8 shards in one go it is a lot more palatable. Farm the shards by collecting treasures in Zul’aman, and once you have 8 do an abundance event, then farm 8 more. You will almost get a full extra profession gear per character you can be bothered to do this on, which will help your profits.
# Set up another alt
You may have time to set up another profession alt. With higher demand and a new season even less optimized set ups will be profitable again for concentration. My main suggestion would be alchemy + enchanting, but there are other combinations. Alchemy is the main one however, and likely to remain the top dog for all of 12.1.
# Prepare for the new recipes
There are several new recipes coming, some of which require preparation. In particular we have inscription looking very relevant with the vantus rune chaining enabling a lot of value by stacking the optimal epic profession tools to get max value from every step.
There are also new decor recipes that can be traded on the AH that come from fishing, so fishing is getting a boost, and depending on the rarity these might sell for a pretty penny. Any characters you are planning to get new recipes on should be leveled to 90, as most of the new 12.1 recipes are from the new zone. The best way to check which you might need is to check the wowhead search for 12.1 items linked below to see what the new recipes are.
