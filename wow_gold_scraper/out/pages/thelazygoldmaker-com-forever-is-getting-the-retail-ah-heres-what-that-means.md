# Forever is getting the retail AH, here's what that means - The Lazy Goldmaker

So I’ve spent a little bit of time on the WoW forever beta and as I was assuming we are getting the new AH, so let’s talk about how it works.
# Stack sizes are gone
The one really big change is for any stackable items like materials, potions etc. Any stackable item is now simply sold and bought in specific quantities. In stead of posting potions in a stack size and at a price I can post any amount of potions at the same price and they will all be posted. You can buy however many you want and it will pick the X cheapest where X is the amount you buy.
# Last in first out
Now what happens if there’s 1000 items at the same price and someone buys 50? Well, he will get the 50 that were posted most recently. So that means that for any high volume item the best approach is usually to post a small ish quantity and then repost almost immediately. With the high populations I expect items will sell really quickly in high volume markets. Generally speaking reposting at the current price more often is the best approach to get profits, but you can consider larger undercuts if the price is too high.
# Gear works the same
Gear and any other items that cannot stack will work exactly the same as they do on the old AH. There’s no real difference here. They can have bid prices and buyout prices.
# Auctionator by default
The default UI is now very close to auctionator, and a lot more functional than the old classic AH UI. You can get a lot done with the base UI, but TradeSkillMaster is still an absolute power multiplier. The main value is posting many different items quickly, as well as doing consistent reposting, like posting potions before raid times. Outside of TradeSkillMaster for massposting the Base UI should serve you really well.
